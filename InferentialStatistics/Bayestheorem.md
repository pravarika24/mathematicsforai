Bayes Statistics(Bayes theorm)

Bayesian statistics is an approach to data analysis and parameter estimation based on bayes theorm.

Bayes theorm

Probability - independent events
dependent events

on dependent events - 
One event will impact the other event 
P(R and Y) = P(R) + P(Y/R)

P(Y/R) - conditional probability

P(A and B) = P(B and A)
P(A)*P(B/A) = P(B)*P(A/B)

P(A/B) = P(A)*P(B/A)/P(B) -- A,B events
P(A/B) - Probability of A given B is true
P(B/A) - Probability of B given A is true

P(A),p(B) - Indepent probability of A and B
